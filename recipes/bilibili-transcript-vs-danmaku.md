# B 站视频转文字：CC 字幕、语音稿和弹幕怎么选？

先确认你要的是哪份文字。它们可能出现在同一段视频里，但不能互相替代。

| 你要找什么 | 先看哪里 |
| --- | --- |
| 视频选定的字幕轨，或字幕作者提供的译文 | 播放器里的 CC 字幕选项。记录具体分 P、语言和来源；可用选项取决于视频。 |
| 视频里实际说了什么 | 先听原声。有权处理该视频且确实需要另做转写时，可以用语音转文字，再校对专名和时间。 |
| 写在画面里的标题、演示参数或内嵌字幕 | 看对应画面。只听音频不一定能拿到这些字。 |
| 观众在对应时间发了什么 | 看弹幕，和视频内容分开标注。弹幕不是说话人的原话。 |

[B 站官方字幕操作指南](https://www.bilibili.com/video/av732569924/)介绍了字幕功能。[TubeText 的 B 站转写输入说明](https://apify.com/tubetext/bilibili-video-transcript/input-schema)描述的是用 Whisper 生成语音稿，可选 SRT；英语摘要是另一个功能，给标题、摘要和要点，不是逐句英文字幕。需要字幕作者的原译时，优先核对可访问的原字幕来源，不要把付费语音稿当成原稿。确实需要新转写时，先看[当前价格](https://apify.com/tubetext/bilibili-video-transcript/pricing)。

**虚构示例：** P2 的 01:24，讲者说「把阈值调到零点五」，画面写着「0.50」，英文 CC 写的是 “Set the threshold to 0.5”，弹幕问「这个是默认值吗」。引用讲者时以原声和 P2 时间为准；引用英文 CC 时标明那是字幕译文；分析观众疑问时才引用弹幕。已有文本能完成工作就不用重跑。

本例不是实跑，也不表示可导出 B 站原始 CC、弹幕或识别画面文字。
