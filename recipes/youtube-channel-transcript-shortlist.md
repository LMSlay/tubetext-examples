# List a YouTube channel’s uploads before fetching transcripts

By TubeText Labs · Documentation checked November 27, 2026

If you want to read three videos from a channel, you don't have to transcribe the whole channel. Keep discovery, caption retrieval, and any paid speech recognition as separate steps.

## 1. Build a metadata-only shortlist

For a few videos, use the channel's Videos tab and copy the specific public watch links you need. If you're building a recurring inventory, follow [YouTube’s uploads-playlist guide](https://developers.google.com/youtube/data/guides/implementation/videos): get the channel's uploads playlist via `channels.list`, then list its items with `playlistItems.list`. To get durations by video ID, use [`videos.list`](https://developers.google.com/youtube/data/reference/rest/v3/videos/list) with `contentDetails`. Save only the metadata you need per [YouTube’s API policies](https://developers.google.com/youtube/terms/developer-policies), including restrictions on storage and refresh.

Make a shortlist by stable video ID, topic, date, or duration. A title and description can help you choose what to open; they don't tell you what was actually said. This metadata step neither downloads captions nor starts a TubeText run.

## 2. Retrieve captions only for chosen videos

The [TubeText YouTube Transcript input schema](https://apify.com/tubetext/youtube-transcript-fast/input-schema) accepts individual video links or IDs under `urls`. Pass those rather than a channel link, which asks the Actor to find and process multiple videos. Set `aiFallback: false` explicitly if you don't want Whisper for videos without captions: the documented default is **on**.

- An existing caption can have been uploaded by the creator or generated by YouTube. Turning off Whisper doesn't require human-written captions or guarantee the preferred language. Inspect what came back.
- If no usable transcript comes back, label that clip as pending or unavailable in your collection rather than marking it as silent. Keep fetch errors separate from missing captions when the returned status permits it.
- Store only data you are allowed to keep. If you already have an authorized transcript for the same video and suitable language, use it instead of sending another request solely to populate the same reading queue.

**Fictional example:** You discover 12 uploads and choose three. One already has a usable transcript; send only the other two watch links. If one returns captions and the other doesn't, record one returned transcript and one unresolved item. Keep AI off unless you decide that the unresolved item merits a separately budgeted pass.

## 3. Estimate charges from actual events

At the time of review, [the event pricing](https://apify.com/tubetext/youtube-transcript-fast/pricing) lists US$2.50 per 1,000 delivered transcripts on the Free plan, a separate Actor Start event, and a separate AI-minute charge if AI transcription is used. For two delivered caption transcripts, one Actor Start event, and no AI minutes, the event calculation is **US$0.00505** before credits. A no-transcript result can carry no result fee while the run still incurs Actor Start. Use the current pricing and your run settings before collecting more.
